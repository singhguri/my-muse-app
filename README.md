# My Muse for Android

My Muse gives each invited person a private workspace. Open the invite link shared by the app owner to create yours, save your recovery key, then install the Android app from the latest release. Sign in to the app with that recovery key. In Apps, add your own OpenAI API key for AI chat and tasks.

[Download the Android app](https://github.com/singhguri/my-muse-app/releases/latest/download/My-Muse-Android.apk)

This repository hosts Android releases only. Source code and server data are private.
